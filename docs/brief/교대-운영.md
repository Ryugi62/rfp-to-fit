# 교대 운영 — 사람·Codex·Claude 누가 잡아도 같은 결과

## 낮(현장 노트북, 브랜치 day/laptop)
```
git clone https://github.com/Ryugi62/rfp-to-fit && cd rfp-to-fit   # 처음 1회
git checkout day/laptop && git pull origin main
cp <키 파일> .env      # GEMINI_API_KEY=... (절대 커밋 금지)
codex                  # 첫 말: "AGENTS.md대로 HANDOFF 다음 1개부터 이어서 해"
```

## 밤(iMac, 브랜치 night/imac) — 사람이 자는 동안 무인으로
```
cd ~/dev/rfp-to-fit && git checkout night/imac && git pull origin day/laptop
caffeinate -dims codex exec -s workspace-write -c sandbox_workspace_write.network_access=true \
  -c 'sandbox_workspace_write.writable_roots=["/Users/ryugi62/dev/rfp-to-fit/.git"]' \
  "AGENTS.md대로 HANDOFF.md의 다음 1개부터 체크리스트 끝까지 이어서 해. 30분마다 커밋·push, 멈출 때 HANDOFF 덮어쓰기."
```
- 9/30 17:1x 실측: `-s`와 `--approve-for-me`는 같이 못 쓴다(오류) · 샌드박스는 `.git`을 읽기 전용으로 막아 커밋 실패 → `writable_roots`에 `.git`을 넣어야 커밋된다 · 네트워크 옵션으로 IRIS 301·PyPI 200 확인.
- `caffeinate -dims`가 그 명령이 살아 있는 동안 잠자기를 막는다(9/23 실측).
- 한 번 끝나면 멈춘다 → 체크리스트가 남았으면 같은 명령을 다시 실행(HANDOFF가 이어 준다).

## 아침 07:00 합치기(노트북)
```
git fetch && git checkout main && git merge --no-ff origin/night/imac && git merge --no-ff origin/day/laptop && git push
```
와이파이가 안 되면: iMac `git bundle create night.bundle origin/main..night/imac` → AirDrop → 노트북 `git fetch night.bundle night/imac:refs/remotes/bundle/night && git merge --no-ff bundle/night`.
